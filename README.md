This is a now defunct set of C libraries and Python scripts for working with the asset files of Crash 1.

Uploaded purely for the sake of archiving my own work. 

In particular, with enough setup/fixing, the pylibcrashutils/utils/gen_level.py script can be used to automatically generate .NSD/.NSF files from a Wavefront (.obj) model. (Results will not be perfect as this was still a WIP.)
